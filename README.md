## 每项都是可独立复制的 Prompt

在任意卡片展开「看用法」，复制完整 Prompt，连同本次正文、真实数据或现有 HTML 一起交给其他 AI 或同事。Prompt 已包含具体规则、所需材料、实际色值、字体、窄屏要求、内容边界、交付和验收标准；无需了解本册编号、访问网站或读取聊天。若未附内容，Prompt 会要求先列缺少的材料，不会把示意数据填进报告。

点顶部「搜索」或「我的收藏」，展开「分组管理 · 备份 · 全部 Prompt」，可一键下载全部。公开的《全部Prompt_可直接复制.md》包含默认的 193 项（50 布局、21 色板、40 图表、68 组件/组合、5 字体、9 文字角色）。浏览器导出的文件还会带上当前个性化设置、自选色板与已保存搭配，所以条目数可能更多。

## 字体与四层文字

在「配色与文字」选择胡晓波青年宋或 Freeland，也可以让大标题、小标题、正文、注释各用不同字体、颜色、字号、字重、行高和段后距。

| 层级 | 默认字号 / 行高 | 默认段后距 | 手机规则 |
|---|---|---|---|
| 大标题 H1 | 40px / 1.25 | 24px | 最大 32px，长标题换行 |
| 小标题 H2 | 24px / 1.4 | 16px | 最大 26px，H3 可进一步分层 |
| 正文 | 16px / 1.75 | 18px | 不因内容多而缩小 |
| 注释 / 来源 | 14px / 1.65 | 12px | 保留完整来源和单位 |

一键字体组合会重设四层的字体与对应原生字重，保留已单独设置的字号和间距；「恢复这组默认」清除当前色板的文字自定项。整页工作台的文字层级预设提供基础值，显式自定的字号/行高/段距优先。Prompt 会列出实际值和哪些字段是用户自定，组件内有明确尺寸建议时，未自定项沿用组件建议。

胡晓波青年宋的字体家族名为 `HuXiaoBo-qingniansong`（细款 300、粗款 700）。Freeland 采用原生 400，适合英文标题，中文按宋体序列回退。网站不附带字体文件；同事电脑未安装时显示回退字体。四层配置随色板、收藏备份和保存搭配一起保留；旧备份可导入并按原字体方案补齐缺少的层级。

## 整页组合与个人收藏

- 在布局区的搭配工作台选择「洞察报告 / 对比提案 / 案例复盘」，配合文字层级、卡片装饰、表格、图表和标注查看一整页；可切换手机宽度。整页内可继续向下阅读，查看示意数据表。
- 点「复制这套完整 Prompt」会带上全部具体规则，不包含人工演示数值。命名保存会保留当时的配色、字体与六项选择；以后恢复搭配时使用保存时样式，在配色 Tab 再做修改则跟随新设置。
- 顶部「搜索」可跨类型检索，支持类型筛选；例如搜“竞品”可找到品牌对比表，搜“导航”可找到目录与侧栏。点「我的收藏」直接看全部已收藏项。展开管理区建分组，勾选搜索结果并加入；分组可包含布局、色板、字体、文字角色、图表与组件。按组查看或复制整组 Prompt；组内互斥样式作为备选，不强制一起套用。
- 收藏组件和保存的整套搭配也会进入顶部「导出收藏清单」。原有布局、色板与图表收藏沿用原记录。

## 导航、缺失状态与手机示例

- D01–D03：常驻分区目录、层级面包屑、返回顶部与阅读定位。
- M01–M04：空收藏引导、无数据与缺字段、无搜索结果与清除筛选、缺失原文链接。
- R01–R02：长标题自然换行、长表格局部滚动。

每项含可操作示意、独立收藏和完整 Prompt。状态由真实内容决定：缺失不填成零，缺链接不生成假入口；长标题保留全文，长表格保留全部字段，手机只在表格内部横向查看。点击目录会定位并移动键盘焦点；搜索弹窗可用 Escape 关闭并回到入口。

## 图表与标注兼容

工作台按当前图型显示可用标注，不能使用的选项会禁用。切换到不兼容图型时，自动改用「图下注释与来源」，并明确提示；保存、恢复、导入和复制 Prompt 使用同一规则。例如桑基图不会再带上数值轴参考线要求，旧的冲突搭配在读取时也会调整。

当前预览的数据标签和均值参考线开放给单序列条形/柱形及折线/阶梯线/面积图；峰值标注开放给三种单序列趋势图。图例/单位和图下注释可随全部 40 图使用。此范围描述本工作台已实现的预览，不是正式报告的图型或标注白名单；正式标注必须先核查真实字段、连续数值坐标轴、范围和来源。

## 备份与恢复

在「我的收藏」或「搜索」里展开管理区，点「下载收藏备份」生成 JSON，含收藏、自选配色、个性化文字设置、分组和保存搭配。到另一浏览器选择该备份，检查导入摘要后点「合并导入并刷新」。只接收本册格式，文件上限 2 MB；无效文件不写入。同编号的配色、文字、分组、搭配保留当前版本，收藏集合合并，当前配色和工作台选择保持不变；导入后可在保存搭配中恢复原方案。

备份包含个人偏好，只在本机读取，不会上传到网站或 GitHub。Markdown 用来分享给人和 AI；JSON 用来恢复网页状态，二者用途不同。

## 最短用法

1. 在「配色与文字」选择色板，选择字体组合，再分别微调四层文字和其余重点颜色，预览立即更新。文字设置按色板分别保存。
2. 「重点色」改变少量关键词的颜色；「加粗」使用独立字色与 700 字重；Highlight 分别控制底色和字色。文字太浅时会调亮度，旁边显示实际使用色。复制、导出都使用这个实际色值。
3. 点「收藏这组文字与配色」，或收藏喜欢的布局、图表。各类收藏相互独立，页面不会替你预选。
4. 点顶部「导出收藏清单」，一起保存成 Markdown；也可单独复制文字与配色说明，或在布局／图表卡片里复制完整用法。

例如：「用 08 分屏封面开篇，正文用 02 主图侧注；用 C02 雾粉雾蓝，标题宋体，重点色与高亮按这份清单；趋势数据检查是否适合 T09 折线图。」

文字的个性化设置随色板保留；切换另一色板时使用另一份设置。点「恢复这组默认」只恢复当前色板的文字和字体，不清除其他色板或收藏。设备缺少某种字体时使用给出的回退字体，不下载外部字体。

## 图表怎么挑

图表区按比较、趋势、构成、分布、关系、流向与层级、时间与目标、文本分为 8 类，也可搜索编号、名称或问题。

每种包含实际图形、适用问题、所需字段、使用提醒、给 AI 的描述，以及可展开回查的完整示意数据表。包括条形、哑铃、坡度、子弹、折线、面积、小多图、排名变化、环形、堆叠、瀑布、帕累托、直方、箱线、区间、散点、气泡、热力、雷达、漏斗、桑基、网络、树状、矩形树、旭日、日历、甘特、仪表、平行坐标与词云等。

**全部图表示例使用人工构造的图型示意数据，不来自业务样本，不用于业务结论。** 图中量程、目标、区间和分界线也是教学设定。导出清单只包含用法与数据条件，不包含这些演示值。正式报告需使用提供或核验后的真实数据；没有数据时应说明缺口。

40 种只是可扩展的常见参考，不是全部图型或白名单。收藏表达偏好；业务问题、字段和证据决定最终是否适用。尤其不能把没有可靠连接依据的搜索、阅读、评论和购买拼成同一漏斗或桑基流向。

## 配色与渐变

预置谷雨粉蓝、雾粉雾蓝、柔粉留白、柔蓝留白、粉金细线。来源与全部色值见《配色索引_给AI.md》。自选色板可设置名称、强调色、辅助色和渐变两端；浅底混入白色，文字适当加深以保持可读。复制描述包含原色与实际使用色值。

渐变用于背景与装饰。切换色板只会更新收藏册自己的预览；正式报告里已有图表的数据、系列颜色含义、坐标轴、图例、visualMap 和交互应保留。新增图表按数据含义单独配色，不把装饰渐变当作数值编码。

## 收藏与离线

双击「HTML布局收藏册.html」即可离线使用。39 种图使用内嵌 Apache ECharts 5.6.0，词云使用 SVG；无 CDN 或在线资源依赖。开源许可与 NOTICE 保留在页面末尾「图表引擎与开源许可」。外部参考链接只在点击时打开。

收藏保存在当前浏览器、当前访问位置。升级沿用原来的布局与配色记录，图表、按色板保存的文字设置分别使用独立记录。线上与本地、不同浏览器或设备不会自动同步；清理站点数据或更改本地文件路径可能无法接续。同一浏览器、同一站点的多个标签页会合并本次改动并同步：分别收藏的条目都会保留，取消收藏也会同步；不同文字字段可以同时调整，修改同一字段以最后保存为准。网站更新后，请刷新已打开的旧页面再一起使用。长期留存请下载 JSON 备份，也可导出 Markdown 分享。复制成功时当前按钮显示“已复制”，并在视口内提示；剪贴板受限时打开完整文字供手动复制。保存失败会提示下载备份，当前未保存改动保留在本页。

布局缩略图仅表示空间结构；示意模块数、章节数和图型不限制正式内容。页面是独立参考，不改动既有谷雨 UI Kit、报告或默认样式。
